Course content

6 units · 34 entries

  • I Introduction to Python 5 Lecture Hours
    • 01 Lecture 1: Introduction to Python, Working with Python, Interactive Mode and Scripting Mode, Basic Syntax, Comments, Indentation
    • 02 Lecture 2: Python Tokens, Variables, and Literals
    • 03 Lecture 3: Python Keywords, Identifiers, and I/O
    • 04 Lecture 4: Mutable and immutable data types, String Values, String Methods
    • 05 Lecture 5: Operators (Arithmetic, relational, logical, assignment, bitwise, membership, identity) and Operators precedence and associativity Open
    • 06 Lecture 6: Type function and id function and Indentation Open
    • 07 Lecture 7: Decision Making Statements and looping structures Open
  • II Collections and Functions 5 Lecture Hours
    • 01 Lecture 1: List Initialization, List Methods, List Operations, Indexing, Slicing, List Comprehension, Nesting in Lists
    • 02 Lecture 2: Tuple Initialization, Tuple Methods, Tuple Operations, Nesting in Tuples, List vs Tuple
    • 03 Lecture 3: Set Initialization, Set Methods, Set Operations, Dictionary Initialization, Dictionary Methods, Nesting in Dictionary
    • 04 Lecture 4: Sorting Data Collections, Typecasting Collections, Applications of Collections
    • 05 Lecture 5: Functions in Python, Parameters, Return Values, Variable Scope, Lambda Functions, map/filter/reduce, Recursion
  • III File and Exception Handling 4 Lecture Hours
    • 01 Lecture 1: File Access Modes, File Handling Functions, Reading/Writing Files, with Statement
    • 02 Lecture 2: Working with Directories, File Handling Applications, Errors vs Exceptions, Exception Hierarchy
    • 03 Lecture 3: Exception Handling (try/except/else/finally), Multiple Exceptions, raise, assert
    • 04 Lecture 4: Modules & Packages, Standard Library, Regular Expressions, Meta Characters
  • IV GUI Programming and Data Connectivity 6 Lecture Hours
    • 01 Lecture 1: Introduction to GUI Programming, Tkinter Basics, Creating Windows and Widgets
    • 02 Lecture 2: Layout Management, Event Handling, Common Widgets (Labels, Buttons, Entries)
    • 03 Lecture 3: Advanced Widgets (Listbox, Combobox, Scrollbar, Canvas), Dialogs and Message Boxes
    • 04 Lecture 4: Database Connectivity with SQLite, CRUD Operations, Using DB Browser
    • 05 Lecture 5: Building a Complete GUI Application, Menus and Toolbars
    • 06 Lecture 6: Packaging and Distributing GUI Applications
  • V Object-Oriented Programming 6 Lecture Hours
    • 01 Lecture 1: OOP Concepts, Classes and Objects, Methods, Attributes
    • 02 Lecture 2: Constructors, Special Methods, Class/Object Variables
    • 03 Lecture 3: Garbage Collection, Abstract Classes, Inheritance
    • 04 Lecture 4: Polymorphism, Method Overriding, Operator Overloading
    • 05 Lecture 5: Encapsulation, Properties, Class Methods and Static Methods Open
    • 06 Lecture 6: Advanced OOP Concepts, Design Patterns in Python Open
  • VI Data Analysis and Visualization 6 Lecture Hours
    • 01 Lecture 1: Introduction to NumPy, Array Creation, Operations, and Attributes
    • 02 Lecture 2: NumPy Operations, Broadcasting, Mathematical and Statistical Functions
    • 03 Lecture 3: Introduction to Pandas, Series and DataFrames, Data Loading and Inspection
    • 04 Lecture 4: Data Cleaning, Transformation, and Aggregation in Pandas
    • 05 Lecture 5: Combining and Comparing DataFrames, Working with CSV/Excel Files
    • 06 Lecture 6: Data Visualization with Matplotlib, Creating Various Plot Types
